SPECIFYING AGENTIC AI LOOPS TOGETHER
Agent Loop Spec (fill in 8 lines):
1. Goal: _________
2. Plan (≤5 steps): [ ] [ ] [ ] [ ] [ ]
3. Tools (name → inputs → output → fail mode): __________
4. Memory to keep: scratchpad / decisions / best template
5. Rubric (0–3 ×3): accuracy • appropriateness • actionability
6. Stop conditions: if score <7/9 → ask human
7. Run log: step • decision • result • next

FIVE AREAS TO BOOST AGENTIC EFFICACY
Agents are powered by these core capabilities:
Autonomy
How far the agent can run independently without human 
intervention.
Reasoning & Planning
Turning high-level goals into clear, checkable execution steps.
Memory
Scratchpad → Episodic log → Reusable knowledge notes.
Tool Use
Using APIs and apps as verbs with structured inputs and 
outputs.
Governance
Defining the essential rules and safety guidelines for the agent.

HOW TO PICK THE RIGHT LEVEL OF AUTONOMY
12
Re-evaluate your current Agentic Loop 
and list yours in the project ideas channel 
There are 4 levels of autonomy
● L0 Macro: one-shot; human 
executes steps
● L1 Confirm: agent proposes, you 
approve
● L2 Loop/Stops: agent iterates, must 
pass checks
● L3 Free-run: rare; only for highly 
repeatable tasks
